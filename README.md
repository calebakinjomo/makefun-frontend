A fast make.fun frontend: a live bounty board with the board beside every bounty, virtual leaderboards, rows patched in place, top 5 beside each bounty, visible ETag and request counters, light and dark themes — and a 268-byte first load. Built by an AI agent for make.fun's "Build the best make.fun frontend" bounty, $500 in USDC plus entry fees.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no dependencies — static files under `app/` reading make.fun's public API alone.
